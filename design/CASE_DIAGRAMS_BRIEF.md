# 案例頁示意圖 — Voxel 版（每案 2 張：現況 / 交付物）

> 先讀 `VOXEL_STYLE_GUIDE.md`。每個 prompt = 風格指南 §2 共用前綴 + 下面場景描述。
> 存檔：`assets/img/src/voxel/diagrams/<slug>-1.png`（現況）、`<slug>-2.png`（交付物），皆 1536×1024。
> 「現況」用**分散、對不上、混亂**的構圖；「交付物」用**集中、對齊、一條線**的構圖——兩張並排就是故事。

## A frozen-food（冷凍食品經銷沖帳診斷）
**frozen-food-1（現況）**
```
[共用前綴] +
On the base tile, three small separate voxel desks placed apart from each other, each with a tiny faceless
voxel worker: the first desk (warehouse) has a stack of pale-blue slips and a frozen box, the second (sales)
has a clipboard and a small brand-blue delivery van parked beside it, the third (accounting) has a calculator
block and a cash tray. The three slips on the desks are clearly different shapes and do not line up. Empty tile
space between the desks. One tiny amber cube fallen on the floor between the desks.
```
**frozen-food-2（交付物）**
```
[共用前綴] +
On the base tile, one long light-wood table; the three different slips now sit side by side in a single
aligned pale-blue voxel ledger board with rows and columns of small cubes; a voxel magnifying glass rests over
one row where a single amber cube is highlighted; beside the ledger a tiny bar chart made of stacked brand-blue
cubes of different heights. Tidy, everything aligned to the grid.
```

## B marital-property（婚後財產交易追溯）
**marital-property-1（現況）**
```
[共用前綴] +
On the base tile, three untidy piles of voxel paper statements on three different small tables — one pile
pale blue (bank), one white (fund), one light grey (dividends) — with loose sheets scattered on the tile
between them and two flipped-over voxel calendar pages. No order, no line connecting them.
```
**marital-property-2（交付物）**
```
[共用前綴] +
On the base tile, a single long voxel timeline ribbon from back-left to front-right with the statements now
sorted along it as small cubes; a brand-blue vertical voxel post marks the middle (the wedding date), the
ribbon is pale blue before the post and white after; at the front end a neat white voxel folder with a tidy
table of cubes and a small ink-grey balance scale, level.
```

## C trip-pricing（旅遊行程估價原型）
**trip-pricing-1（現況）**
```
[共用前綴] +
On the base tile, a travel-agency desk with a very thick pale-blue voxel binder standing upright (many pages),
and a voxel laptop whose screen shows a spreadsheet grid of cubes where several cells are missing (holes);
a tiny faceless voxel worker points at the binder. A folded voxel map with pins lies at the side. One amber
cube sits in one of the missing spreadsheet cells.
```
**trip-pricing-2（交付物）**
```
[共用前綴] +
On the base tile, a voxel laptop screen showing a clean pricing form built from aligned pale-blue and
brand-blue blocks with a total block at the bottom; next to it a white voxel checklist board with seven small
puzzle-shaped cubes laid out in a row (the found gaps), and a column of thirteen tiny brand-blue check cubes.
Calm and orderly.
```

## F video-production（多門市影片產線）

```
[共用前綴] +

```

